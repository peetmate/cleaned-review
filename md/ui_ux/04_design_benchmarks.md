# 04 · Design benchmarks: how proven farm / livestock tools structure data entry

Purpose: adapt, not invent. This note surveys well-regarded tools that describe farms or livestock systems and extracts the UX patterns worth borrowing for the iCLEANED data-entry redesign (Home/scenarios → Location & climate → Plots → Seasons → Herds & animal groups → Feeds → Manure & inputs → Feeding plan → Check & run → Results).

Evidence basis: official user guides / manuals were read in full for Cool Farm Tool (livestock), Agrecalc Cloud, GLEAM-i 2.0, CAP'2ER (methodological guide + brochure), COMET-Farm, Farm Carbon Calculator, Bord Bia/Teagasc Carbon Navigator, FEAST data application and EX-ACT quick guidance. Farm-management and farmer-facing apps (AgriWebb, Herdwatch, Breedr, Farmbrite, farmOS, Ruminati, MLA calculator, iCow, Nuru, Plantix, Farmer.Chat, Hello Tractor) were assessed from official product pages, help centres and published evaluations. Anything not directly observed is marked **(inferred)**.

## 2. Farm-description sequences observed

- **Cool Farm Tool livestock**: General (system type, organic, reference period, name) → Production/Milk (breed → default weights, yield, fat/protein defaults) → Herd table → Grazing (days, h/day, type, quality per category; grassland area + fertiliser) → Feed (DMI per feed per category *or* % mix) → Manure (% per MMS per category; bedding) → Energy → Transport → results/duplicate.
- **Agrecalc**: Farm report (name, year-end, avg temperature default 10 °C, sectors, groups, classes, enterprise type) → Land & Crops (areas, fertiliser, imported manures, transferred manure, pesticides, production & use, crop→livestock allocation, biochar, soil C) → Livestock (numbers & weights → purchases/sales/deaths → performance → manure → purchased feed → bedding → ration) → Energy & Waste → Results (whole-farm, enterprise KPIs, charts, benchmarks).
- **GLEAM-i**: Start (name, region, country → defaults loaded) → Herd → Feed → Manure → Results (Baseline vs Scenario).
- **COMET-Farm animal ag**: Project → Animal location (state/county) → select animal categories/types (+ groups) → per type: Animal details (monthly head, weight) → Feed (monthly, or Feed Calculator) → Housing (% time/month) → Manure follow-ups → Scenario (optional) → Report.
- **FEAST**: Project → Site (country, currency, pasture nutrition defaults, custom feed sources) → Focus group tabs → Individual interview tabs (General, Property/Income, Livestock holding, Crops, Fodder & diet, Livestock sales, Milk, Feed availability by month).
- **Carbon Navigator**: select farmer (prefilled) → 5 base facts → six measures Current/Target → Update → chart vs peers → advice sheet → print.
- **CAP'2ER**: Diagnostic (L1 27 items / L2 150 items) → positioning vs reference group → action plan → monitoring/simulation.

## 3. Synthesis 1 — the 10 most transferable patterns for iCLEANED

1. **Two explicit depth levels with published defaults (CAP'2ER L1/L2; MLA Quick Start; GLEAM-i defaults; EX-ACT Tier 1/2).** Offer "Quick (≈30 min, ~25 questions)" and "Detailed" modes. Quick mode fills everything else from region/system defaults and *shows the list of assumptions it made*. Apply on Home (mode choice per scenario) and surface the assumption list on Check & run.
2. **Set-up wizard that prunes later screens (Agrecalc report set-up; COMET category selection).** Ask up front which species, systems and plot types exist; only those rows/cards appear in Herds, Feeds, Manure. Apply on Home → Location: "What's on this farm?" checklist.
3. **Herd as one table of fixed categories with counts and weights, breed-driven defaults (CFT Herd; Agrecalc classes; FEAST livestock holding).** Fixed rows (e.g. lactating cows, dry cows, heifers, calves, bulls, draught) × {number, avg live weight}; pick breed → weights, milk yield, fat % prefill and stay editable. Running total of head and TLU (GLEAM-i "total animal numbers" live cell). Apply on Herds & animal groups.
4. **Percent-share rows with a live 100 % check, coloured green/red (GLEAM-i ration & MMS; Agrecalc red cells; COMET housing/solids; CFT manure).** Use for manure system shares, diet shares per season, time-on-plot shares. Apply on Manure & inputs and Feeding plan.
5. **Season × month mapping and per-season ordinal scores (FEAST rainfall 0-5, feed availability 0-10; COMET monthly tables with copy-across arrows).** Seasons defined by clicking months; a diet or grazing pattern entered once and copied to other seasons with one action. Apply on Seasons and Feeding plan.
6. **Persistent progress roadmap with four states and a locked Run button (COMET roadmap; Agrecalc Next/auto-save; FCC section toggles).** Header shows each iCLEANED section as complete / incomplete / unavailable-with-reason / current; Check & run lists the blockers. Auto-save on Next.
7. **Location → auto-derived climate/soil, with edit affordance (COMET SSURGO/PRISM; Agrecalc soil C by postcode; EX-ACT climate/moisture/soil choice).** Pin on map or pick admin unit → temperature, rainfall, AEZ, soil class prefilled and marked "from map – edit". Apply on Location & climate; draw or GPS-walk plots as simple polygons with area auto-computed (farmOS, FieldView, Hello Tractor agents' land tool).
8. **Live or near-live results panel and side-by-side scenario comparison (FCC live CO2e; GLEAM-i Baseline vs Scenario with % change; CFT "save as" duplicate; Carbon Navigator current vs target).** Duplicate a scenario, change one thing, compare. Apply on Home/scenarios (duplicate) and Results (two-column, % deltas, regional reference band).
9. **Contextual help on every field plus a printable data-collection form that mirrors the screens (CFT hover "i" and notes box; FCC collation spreadsheet; FEAST printable forms; COMET data-entry spreadsheets).** Ship a one-page paper/PDF checklist in the same order as the UI so an enumerator can interview first and key later, offline. Apply globally; the checklist becomes the FEAST-style field form.
10. **Advisor-on-behalf-of-farmer with consent and a validation step (Carbon Navigator SMS code; Agrecalc consultant validators; CAP'2ER certified data collection; Hello Tractor booking agents).** Accounts have farms; a "collected by / farmer consent recorded" stamp; an optional reviewer flag before results are shared.

## 4. Synthesis 2 — low-bandwidth / low-literacy patterns (FEAST, Nuru, iCow, Farmer.Chat, Hello Tractor)

- **Offline-first with deferred sync** (FEAST desktop app with export file; AgriWebb/Herdwatch/Breedr mobile). For a web tool: local storage of the draft, explicit "Saved on this device / synced" indicator, and the model run as the only network step **(inferred design consequence)**.
- **Ordinal scores instead of quantities where farmers cannot give numbers** (FEAST 0-5 rainfall, 0-10 feed availability summing to 10, 0-4 issue severity). Use for seasonal feed availability and pasture quality; convert to model quantities behind the scenes with visible defaults.
- **Intermediary-centred design**: Nuru phones given to extension officers; Farmer.Chat deployed to agents as a human-review layer; Hello Tractor booking agents. Design iCLEANED for the enumerator/adviser as the hands-on user, with a farmer-facing printable summary.
- **Local units and names**: FEAST defines custom units by kg equivalence and marks them "local"; use debe/bundle/bag with a conversion the enumerator sets once per site.
- **Language and voice**: Nuru advice offline in Swahili/French/Twi; Farmer.Chat voice-in/TTS-out; iCow parity across SMS/USSD/app. Minimum for iCLEANED: short plain-English labels, icon + label for categories, glossary tooltips; Swahili/French/Amharic/Vietnamese label files as a later step **(inferred)**.
- **Keep page weight tiny**: iCow and USSD show the floor; Farmer.Chat found *data cost*, not literacy, was the binding constraint. Avoid map tiles by default (offer "pick district" first, map second), no heavy chart libraries on entry screens **(inferred)**.
- **Short video/prompt onboarding** (Farmer.Chat 20-30 s clips, Plantix tutorials, Ruminati in-person onboarding events).

## 5. Synthesis 3 — how the best tools handle "unknown" and defaults

- **Default is always visible and editable, never blank**: CFT fills breed weights, fat/protein, feed source region; Agrecalc prepopulates ADG, digestibility, CP, manure N/P; GLEAM-i loads a full country default set and colour-codes locked default vs editable baseline; EX-ACT drop-downs of IPCC defaults.
- **Defaults are explained and scoped**: CAP'2ER publishes each Level-1 forfait; Agrecalc says "use farmer estimates or industry default values … consultants will assess feasibility"; CFT's guide gives DMI ranges by yield class as sanity anchors.
- **Leave-blank rule is explicit**: FCC "if not applicable, leave it out"; EX-ACT "normal for many cells to remain empty"; Agrecalc soil C "leave blank and we use postcode default". Blank = default, not zero.
- **Alternative entry routes for the same fact**: Agrecalc offers "Urea / Other N / Other P" pseudo-products when fertiliser brands are unknown; CFT offers precise DMI or % mix; MLA Quick Start derives class distribution from a single total.
- **Derived quantities shown back**: GLEAM-i total animals; CFT grazing-derived grass DMI and pasture manure "already calculated – do not add again".
- For iCLEANED: every field gets a three-state control – *entered*, *default (source shown)*, *don't know → use default*; the Check & run page lists all fields still on default so the user sees the uncertainty they are carrying **(inferred synthesis)**.

## 6. Synthesis 4 — multi-farm, multi-user and advisor workflows

- **Hierarchy**: FEAST Project → Site → Group → Respondent, with site-level facts (country, currency, pasture nutrition) inherited downward; COMET project → fields/animal types with copy-between-fields; CFT one farm per account by default, multi-farm switch for members; Agrecalc farm → reports (years) → enterprises/groups.
- **Roles**: Agrecalc farmer / consultant / supply-chain users with consultant validation; Carbon Navigator adviser dashboard listing authorised vs unauthorised clients; Ruminati producer accounts plus corporate VISION dashboards fed only by opt-in sharing.
- **Consent and privacy**: Carbon Navigator SMS authorisation code; CFT footprints private by default, shared via share code with farm name optionally removed; Ruminati data revocable at any time.
- **Reuse across years/scenarios**: CFT "save as"; COMET duplicate project and copy management; FCC compare reports; Agrecalc "future entries ~1 h" because structure persists.
- For iCLEANED: Organisation → Site (defaults) → Farm → Scenario (year or what-if); collector and farmer fields on each farm; share-code export of anonymised results **(inferred application)**.

## 7. Synthesis 5 — how livestock GHG calculators structure herd and manure inputs

| Aspect | CFT | Agrecalc | CAP'2ER | GLEAM-i | COMET-Farm | Ruminati/MLA |
|---|---|---|---|---|---|---|
| Herd unit | 6 fixed age/sex categories per module | Class list per group (10 cattle classes) with definitions | Animal categories with N-excretion forfaits (L1) | Reproductive adults + parameters → derived cohorts | Animal types (+ up to 3-5 groups) with monthly head/weight | Species totals; regional class split (Quick Start) |
| Numbers | Average on-farm + sold + purchased (deaths excluded) | Average over 12 months; opening/closing weights; purchases, sales, deaths, KO % | Effectifs par catégorie | Adult count; fertility/mortality/replacement | Monthly population | Annual average |

Common denominators worth adopting: fixed category rows; average-count semantics stated in the UI (snapshot vs opening/closing average, with both illustrated in CFT's guide); manure as *time-share* per category across a short IPCC-based list; grazing deposition derived from grazing time rather than asked; performance KPIs optional but displayed.

## 8. Synthesis 6 — five things NOT to copy

1. **Spreadsheet-first delivery** (GLEAM-i, EX-ACT): macros, colour codes as the only affordance, no validation beyond cell colour. Keep colour codes but as a secondary cue with text state.
2. **Making the user do the model's arithmetic** (Agrecalc pesticide area ÷ sprays; Agrecalc lime annualisation; CFT pre-averaging herd numbers by hand). Ask for the raw fact and compute.
3. **Mandatory two-pathway detours** (CFT: assess feed crops in the crop module, save as feed item, come back). Keep feeds and plots in one flow; link plot → feed inside the Feeds screen.
4. **Deep conditional nesting for manure** (COMET housing → separator → solids/liquids → storage length → temperature). iCLEANED's context needs ~6 MMS options and a % time share; put the rest behind "Detailed".
5. **Dependence on infrastructure the user does not have** (Carbon Navigator national databases; FieldView CLU polygons; Herdwatch registry sync; Plantix always-on data). Design for paper-first, offline draft, admin-unit fallback before map.

Also avoid: 9+ equal-weight sections presented as a wall (FCC/Agrecalc first-time 2-2.5 h); permanent cascade delete with a single warning (FEAST); adviser-only access with no farmer-facing summary (Carbon Navigator, Alltech).
